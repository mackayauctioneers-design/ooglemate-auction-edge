# Architecture rules

- VPS winner-cell write-back uses the existing token-authenticated sales-ingest conduit and canonical dealer_fingerprints; encode account + level + cell_key as a namespaced fingerprint_id (km_band is already represented in exact cell keys), resolve the profile server-side, reject private/raw fields, and preserve site approval/settings so importing cannot create alerts or a parallel buying engine.

- Public market statistics are fetched directly from the VPS public aggregate endpoint by one small query hook; keep this page independent of authentication and backend functions to preserve the public read-only boundary.
- The portal desk reads only the VPS desk queue, DNA, stock, auctions, summary and activity using the portal session bearer token and no cookies; prices, stages, gaps and counters are server-supplied (never derived), and synthetic fallback is restricted to development and Lovable preview hosts to preserve tenant isolation and the read-only boundary.
- Desk summary and incremental worker activity use an independent 60-second read-only hook with timestamp cursor, deduplicated newest-first events and auth-change resets, so polling cannot disturb existing desk panels or retain a previous account's events.
- Desk valuations reuse wholesaleApi.guide without a second pricing client; desk-only result rendering and polling retain the guide's held and live-check send gates, and related cars reuse the desk queue card to keep figures and dealer isolation consistent.
- Wholesale entry may initialize its fields from link parameters, but odometer confirmation stays false and the existing guide/send flow remains mandatory to prevent pre-fill from bypassing validation.
- The root Trading Desk boundary resolves operator access from the existing server role RPC and checks wholesale buyer identity before mounting the operator desk; auth changes clear the prior view, so root routing does not weaken wholesale privacy.
- Trading Desk presentation reuses loaded operator opportunities for charts and trend indicators, the public statistics hook for market totals, and OogleVal for guide results; omit inconsistent market breakdowns and empty charts, keep the charts beside valuation and span the opportunities list the full page width below them, and leave missing floor gaps blank rather than substituting another anchor. Trading Desk opts out of valuation error fallback and allows details without state; portal desk defaults stay unchanged.- Ooglecars portal sign-ins reach the Trading Desk only through the operator-desk gateway: it verifies the Ooglecars JWT via JWKS, grants yard scope only from the caller's own dealership_members rows with role owner plus yard_links (owner_access = all yards), allows writes only on cars currently assigned to the caller's yard or unassigned and best-matched to it, and keeps cross-yard actions owner_access-only as fixed allow-listed actions with no generic passthrough; the browser never sends a yard.
- Desk freshness rules (120-day price anchors, best fit only for yards with own sales in 120 days, auction-ended / source-gone / 36h-stale expiry, Sydney "Ends …" labels) live in one pure module, supabase/functions/_shared/deskFreshness.ts, used by the scorer, fingerprint matcher, Telegram alerts, operator-desk and the desk page, so every surface applies the same cut-offs. Auction end times are stored in vehicle_listings.auction_datetime (UTC end) and filled per auction event by auction-end-lookup, never per lot.
- Carsales well-below-market on the Trading Desk is owner_access-only via the operator-desk wbm_list action and renders nothing without fresh data, keeping a possible paid dealer feature off yard desks.
- Finder catches and per-source coverage arrive only through sales-ingest's finder_catches / source_coverage actions (strict allow-lists, upsert counts echoed); they are readable only by admins directly and by owner_access via operator-desk caught_list / coverage_list, and Manheim lot ends are filled from the latest manheim coverage sale close via deskFreshness.withManheimEnd without overwriting a real per-lot end, so dealers never see catch data and every surface shares one end-time rule.
